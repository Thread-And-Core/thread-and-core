# Thread & Core Systems Website Experience Prompt

Use this document to guide the website experience, information architecture, homepage flow, page structure, pre-hero explanation, hero content, Thread & Core Framework presentation, animation direction, and video/image asset strategy for Thread & Core Systems.

This document is website-focused. It intentionally does not include build approach or color system. Use it with Framer, ChatGPT, Claude, Codex, designers, UX strategists, motion designers, or visual asset generators.

## 1. Website Goal

The website should not feel like a generic IT consulting website.

It should feel like the digital identity of a future enterprise technology firm.

The website must qualify the visitor before the first conversation. A visitor should arrive, experience the brand idea, understand the methodology, see proof, understand the founder's credibility, and reach the contact section already knowing whether Thread & Core is a fit.

The website should make visitors feel:

- This is a serious enterprise architecture practice.
- The company understands business and technology complexity.
- The brand has a clear methodology.
- The founder has real production delivery experience.
- The first conversation will be strategic, not introductory.

## 2. Core Website Ideology

The website should tell a story, almost like a short film.

Do not follow the generic structure:

- Hero
- About
- Services
- Industries
- Projects
- Contact

Instead, the visitor should move through a brand journey:

1. Invisible enterprise threads appear.
2. The threads are shown as disconnected.
3. They begin connecting.
4. They converge into the Core.
5. The company name becomes understandable.
6. The hero states the category.
7. The manifesto explains the belief.
8. The framework explains the methodology.
9. Capabilities and proof build confidence.
10. The founder becomes credible.
11. Contact feels like the natural next step.

The website itself should explain the company name.

## 6. Pre-Hero: Thread Genesis

### Purpose

The pre-hero must explain the company name without using a paragraph.

It should visually demonstrate that enterprises are made of invisible threads, and that Thread & Core connects those threads to a stabilising core.

### Experience

The page opens with a cinematic but readable full-screen sequence.

The first screen should not feel blank or broken. The visitor should immediately see a meaningful brand statement.

Opening line:

Every enterprise runs on thousands of invisible threads.

Then, as the visitor scrolls, six thread words appear:

- Data
- Processes
- Applications
- Intelligence
- People
- Decisions

Each word should feel like a separate thread or signal. They should appear disconnected at first.

Then the threads begin drifting toward one another.

They connect.

They converge.

A glowing Core appears.

The word CORE appears inside or near the sphere.

The Thread & Core Systems brand resolves.

### Important Pre-Hero Rules

- Do not make the first viewport blank.
- Do not make the visitor scroll too long before anything happens.
- Do not make the sphere tiny.
- Do not make thread labels hard to read.
- Do not rely only on faint blue lines on black.
- The sequence should feel premium, not experimental.
- The animation should support the brand idea, not become the whole website.

### Suggested Scroll Rhythm

The pre-hero should be concise.

Suggested sequence:

1. The sentence is visible immediately.
2. A small instruction or motion cue suggests scrolling.
3. Thread words appear quickly.
4. Threads converge.
5. Core appears as a meaningful visual centerpiece.
6. Hero section follows without excessive delay.

## 9. The Thread & Core Framework

The Thread & Core Framework is the proprietary methodology and the most important business asset on the website.

It should not feel like a generic consulting phase diagram.

It should feel like a method developed through real enterprise delivery.

## 10. Framework Philosophy

Every enterprise transformation has two dimensions:

1. Threads: what connects the enterprise
2. Core: what anchors the enterprise

### Threads

The active moving parts:

- Processes
- Applications
- Data
- Integrations
- Intelligence
- People

Without threads, nothing moves.

### Core

The stabilising anchors:

- Value: business outcomes and financial control
- Resilience: the system absorbs change, scales, and governs itself
- Intelligence: the system learns, adapts, and operates with less human intervention

Without core, nothing sustains.

### Framework Idea

Transformation happens when the enterprise threads connect to the core.

## 12. How to Display the Framework

The framework should be visual, not only textual.

Recommended framework visual:

Understand -> Connect -> Modernise -> Automate -> Scale -> Core

The diagram should feel like one continuous thread passing through five nodes and entering the Core.

### Desktop Experience

- Horizontal living thread
- Five phase nodes
- Current node glows or expands
- Previous nodes remain visible but quieter
- One question appears for each phase
- Three key bullets appear for the active phase
- The thread enters a Core sphere at the end
- The Core stabilises or pulses

### Mobile Experience

- Vertical stepper or accordion
- The thread draws downward
- Each phase expands cleanly
- Keep all text readable
- Avoid complex interactions that make mobile feel broken

## 23. Animation Strategy

The thread metaphor is the signature animation system.

### Primary Animation Motif

A single glowing thread should appear to stitch the site together as the user scrolls.

Behavior:

- Thread draws progressively on scroll.
- It pauses at key sections.
- Nodes glow when activated.
- The line eventually terminates in the Core.

### Thread Genesis Animation

The Thread Genesis sequence should:

- Open with a meaningful sentence, not a blank screen
- Reveal enterprise threads as distinct words or signals
- Show disconnection first
- Show convergence second
- Reveal the Core as a meaningful visual object
- Transition naturally into the hero

### Framework Animation

The Framework animation should:

- Draw a continuous thread across five nodes
- Activate each phase as the thread reaches it
- Show phase questions and capability bullets
- End with the thread entering the Core
- Keep the method understandable even without animation

### Capability Card Animation

Capabilities can use:

- Expand/collapse behavior
- Hover border trace
- Active card glow
- Mobile accordion layout

### Industry Tile Animation

Industry tiles can use:

- Cinematic image tiles
- Subtle hover zoom
- Thread border trace
- Proof statement reveal

### Reduced Motion

Respect reduced motion preferences.

If reduced motion is enabled:

- Disable complex scroll-scrub animation
- Show static Core visual
- Keep content fully accessible
